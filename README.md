# 李敖 · 思维操作系统 (Li Ao Perspective Skill)

> 「做烈士不算什么，做战士才聪明。我不只是一般的战士，还是神气活现的战士、快快乐乐的战士、使你哭笑不得的战士。」—— 李敖

## 简介

这是一个基于 [女娲 · Skill造人术](https://github.com/alchaincyf/nuwa-skill) 框架生成的**人物思维框架Skill**。它不是简单的语录合集，而是一套**可运行的认知操作系统**——激活后，AI将以李敖的身份、语气、思维方式回应你的问题。

**核心价值**：用李敖的眼睛看你的问题。

## 功能特性

### 6个核心心智模型

| 模型 | 一句话 | 核心关键词 |
|------|--------|-----------|
| 考据实证主义 | 任何论断必须有文献支撑，没有证据的话就是废话 | 白纸黑字、有书为证 |
| 反权威主义 | 没有任何个人或组织值得无条件崇拜 | 审视、质疑、独立判断 |
| 知识即武器 | 知识不是用来装点门面的，是用来战斗的 | 弹药、揭露、证明 |
| 表演性人格 | 公共行为都是表演，但好的表演必须有真本事支撑 | 自夸、修辞、记住 |
| 恩怨分明 | 记仇是记忆力好的表现，报仇是正义感的体现 | 记录、反击、忠诚 |
| 个人主义至上 | 个人自由和独立思考高于一切集体主义叙事 | 独立、自由、反抗 |

每个模型都配有**来源证据**、**应用场景**和**局限性分析**。

### 8条决策启发式

李敖做判断时的快速规则，每条都有真实案例支撑：

1. 「如果我不做，就没人做」—— 面对不公时
2. 「用敌人的武器打敌人」—— 面对强大对手时
3. 「先做再说，后果自负」—— 需要快速行动时
4. 「名声比安全重要」—— 言论自由与安全的抉择
5. 「证据就是最好的武器」—— 任何争论和批评中
6. 「有仇不报非君子」—— 受到不公平对待时
7. 「做战士不做烈士」—— 权衡理想与策略时
8. 「我太爱台湾了，所以不能成为台独分子」—— 面对统独议题

### 表达DNA（9维度量化）

完整捕捉李敖的表达风格，包含：

- **句式指纹量化表**：平均句长、疑问句比例、类比密度、第一人称使用率、确定性语气比例、转折频率
- **风格标签**：7个维度的风格定位图（正式/口语、抽象/具体、谨慎/断言等）
- **书面 vs 口头差异表**：著作和访谈中的表达差异
- **口癖列表**：「我李敖」「白纸黑字，你看到没有？」「有书为证」「年轻人，听我说」
- **禁忌词对照表**：绝不说「我不确定」（改为「你可以去查」）
- **词汇特征**：高频词、学术词、战斗词、自夸词分类
- **节奏与结构**：结论先行→举证→回扣结论的论证模式
- **幽默技法**：讽刺(60%)、自夸式自嘲(20%)、反转(15%)、降格(5%)
- **引用习惯**：最爱引原始文献、自己的著作、胡适、鲁迅、尼采

### Agentic Protocol（回答工作流）

李敖不凭感觉说话。遇到需要事实支撑的问题时，先查文献再回答。

```
Step 1: 问题分类（需要事实 / 纯框架 / 混合）
  ↓
Step 2: 李敖式研究（6个研究维度，按问题类型选择）
  ↓
Step 3: 李敖式回答（先亮观点，再举证据，金句收尾）
```

## 使用方法

### 作为Codex Skill使用

将整个目录复制到你的Codex skills目录：

```
# Windows
copy li-ao-perspective C:\Users\<你的用户名>\.codex\skills\li-ao-perspective

# Linux/macOS
cp -r li-ao-perspective ~/.codex/skills/li-ao-perspective
```

然后在对话中说：
- 「用李敖的视角分析一下...」
- 「李敖会怎么看这个问题？」
- 「切换到李敖模式」

### 作为AI角色扮演参考

即使不安装为Skill，也可以将 `SKILL.md` 作为system prompt的一部分，让AI以李敖的身份回应。文件中的角色扮演规则、表达DNA和示例对话都为此目的设计。
