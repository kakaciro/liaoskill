# LiaoSkill - AI人物思维操作系统集

> 一套可运行的AI角色认知操作系统。每个Skill不是简单的语录合集，而是一套完整的人格框架——激活后，AI将以特定人物的身份、语气、思维方式回应你的问题。

## 项目简介

LiaoSkill 收集并整理了多位具有鲜明思维特色的公众人物的认知框架，通过深度调研和系统蒸馏，将其转化为可运行的AI Skill。每个Skill都经过多维度质量审计，确保思维模型的准确性和表达风格的真实性。

### 核心价值

- **不是语录合集**：每个Skill都是一个完整的认知操作系统，包含心智模型、决策启发式、表达DNA等核心模块
- **可运行的框架**：激活后AI将以特定人物的视角分析问题，而非简单模仿说话风格
- **质量保证**：每个Skill都经过6维度自动化质量审计，确保思维框架的完整性和准确性

## 包含的Skill

### 1. 李敖 · 思维操作系统 (li-ao-perspective)

> 「做烈士不算什么，做战士才聪明。我不只是一般的战士，还是神气活现的战士、快快乐乐的战士、使你哭笑不得的战士。」—— 李敖

#### 核心特色

- **6个核心心智模型**：考据实证主义、反权威主义、知识即武器、表演性人格、恩怨分明、个人主义至上
- **8条决策启发式**：每条都有真实案例支撑
- **9维度表达DNA量化**：句式指纹、风格标签、书面vs口头差异、口癖、禁忌词等
- **4段示例对话**：覆盖不同场景
- **完整模块**：两性观、时间线、价值观、智识谱系、诚实边界

#### 质量审计

| 维度 | 标准 | 实际 | 状态 |
|------|------|------|------|
| 心智模型数量 | 3-7个 | 6个 | PASS |
| 模型局限性 | 每个有 | 6/6 | PASS |
| 表达DNA辨识度 | ≥3项特征 | 9/9子维度 | PASS |
| 诚实边界 | ≥3条 | 10条 | PASS |
| 内在张力 | ≥2对 | 5对 | PASS |
| 一手来源占比 | >50% | 67.7% (21/31) | PASS |

#### 使用场景

- 「用李敖的视角分析一下...」
- 「李敖会怎么看这个问题？」
- 「切换到李敖模式」

### 2. 东子 · 电商运营思维操作系统 (dong-zi-perspective)

> 「我告诉你，这个很关键。很多人以为流量就是一切，但实际上，流量层级决定天花板。」—— 东子

#### 核心特色

- **5个核心心智模型**：流量层级思维、ROI理性主义、实战验证主义、平台规则解读者、全域视野
- **8条决策启发式**：基于万堂书院首席讲师实战经验
- **9维度表达DNA量化**：句式指纹、风格标签、电商术语体系等
- **3段示例对话**：覆盖诊断、培训、策略场景
- **完整模块**：电商方法论、时间线、价值观、智识谱系、诚实边界

#### 关键信息

- **身份**：万堂书院首席讲师（全国仅5位）
- **平台**：抖音@东子电商、万堂书院@东子
- **业务**：淘宝/天猫运营培训 + 代运营 + 跨境电商（亚马逊）
- **爆款**：「流量层级如何提升」（111.5万赞）

#### 使用场景

- 「用东子的视角分析一下这个店铺问题...」
- 「东子会怎么诊断这个流量问题？」
- 「切换到东子模式，分析一下这个运营策略」

## 安装方法

### 方法一：手动安装

```bash
# Windows
copy li-ao-perspective C:\Users\<你的用户名>\.codex\skills\li-ao-perspective
copy dong-zi-perspective C:\Users\<你的用户名>\.codex\skills\dong-zi-perspective

# Linux/macOS
cp -r li-ao-perspective ~/.codex/skills/li-ao-perspective
cp -r dong-zi-perspective ~/.codex/skills/dong-zi-perspective
```

## 生成方法

每个Skill都经过以下标准流程：

1. **Phase 0**：需求确认与目录创建
2. **Phase 1**：多Agent并行多源信息采集
3. **Phase 1.5**：调研质量审查
4. **Phase 2**：框架提炼（心智模型、决策启发式、表达DNA量化）
5. **Phase 3**：Skill构建（按模板填充）
6. **Phase 4**：质量验证（6项自动化检查）
7. **Phase 4.5**：满分强化（量化表、来源补充、引用扩充）
